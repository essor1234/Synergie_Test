# Evaluator Rubric

| Area | Passing evidence |
| --- | --- |
| User behavior | The intended outcome works through a supported public interface. |
| Safety | Sensitive data is protected and unsafe behavior fails closed. |
| Architecture | Domain, services, storage, API, and UI responsibilities remain separated. |
| Reliability | Expected failures are visible, recoverable, and tested. |
| Tests | Repeatable verification passes with recorded evidence. |
| Scope | The implementation matches the active feature boundary. |
| Handoff | Another person can continue using only repository artifacts. |

Do not accept a feature based only on a mock, configured credential, or undocumented manual success.
