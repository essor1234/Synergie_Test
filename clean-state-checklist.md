# Clean State Checklist

- [x] At most one feature is `in_progress`.
- [x] Relevant repeatable verification passes.
- [x] Evidence is recorded for newly passing work.
- [x] `agent-progress.md` states the current truth and next priority.
- [x] `feature_list.json` and `session-handoff.md` are current.
- [x] No secret, credential, personal identifier, or generated runtime file is included.
- [x] Harness-owned services are stopped when no longer needed.
- [x] Unrelated user changes are preserved.
